## 关键技巧：读蓝图

蓝图 .uasset 无法直接读。方法：编辑器事件图表 Ctrl+A → Ctrl+C → 粘到 txt 发我。文本中 `Begin Object`=节点、`LinkedTo`=连线、`MemberName`/`VariableReference`=函数/变量。已写入 MEMORY.md。

- `08_故事版总结_一场开火大戏.md`：05/06/07 三篇的大白话浓缩版，用"剧院一场开火戏"的故事+图讲清 C++骨架/蓝图血肉/配置道具，以及"特效(全客户端)与伤害(仅服务器)分离"。用户反馈"代码概念太多晕了"，故做此故事版。

- `09_输入_按键到角色运动的故事.md`：输入逻辑故事版。核心链路：按键→Enhanced Input(传令兵)→InputConfig翻译官(物理键→InputTag)→HeroComponent操作台分派。关键分岔：路线A固定功能(Move/Look/Crouch直接调函数,AddMovementInput/AddControllerYawInput)、路线B技能(AbilityInputTagPressed转交ASC)。移动方向取镜头ControlRotation.Yaw(镜头相对移动)。源码证据：LyraHeroComponent.cpp 的 InitializePlayerInput/Input_Move/Input_LookMouse。

- `10_UI三层_UMG_CommonUI_LyraUI人物谱.md`：讲清 UMG/CommonUI/LyraUI 三层区别（继承叠加非并列）。核心：`UUserWidget`(UMG底座,管显示) ← `UCommonActivatableWidget`(CommonUI框架,管操作/导航/多设备/层栈) ← `ULyraActivatableWidget`(LyraUI项目层,加 ELyraWidgetInputMode 输入模式开关)。Lyra UI 用 `PushContentToLayer_ForPlayer` 推进层栈(UI.Layer.Game/Menu/Modal 标签)而非 AddToViewport。数据驱动加 UI：`GameFeatureAction_AddWidgets`(配 LayoutClass+LayerID)。源码证据：LyraActivatableWidget.h / LyraHUDLayout.cpp(Esc暂停+手柄断连) / LyraUIMessaging.cpp(模态对话框) / LyraBoundActionButton.cpp(按设备换皮肤) / GameFeatureAction_AddWidget.cpp。

- `Lyra_项目分析/14_UI目录/01_UI目录总览_文件清单.md`：`Source/LyraGame/UI/` 目录全清单。根目录=UI骨架(基类+全局控件+触摸模拟)：LyraActivatableWidget/LyraHUDLayout/LyraTaggedWidget/LyraSimulatedInputWidget(模拟输入基类)/LyraJoystickWidget(虚拟摇杆)/LyraTouchRegion/LyraSettingScreen/LyraGameViewportClient/LyraHUD(仅debug)。8子目录：Basic(材质进度条MaterialProgressBar)、Common(按钮换皮肤LyraBoundActionButton/列表/页签TabList/WidgetFactory)、Foundation(确认框/手柄断连屏/加载屏/按钮基类)、Frontend(LyraFrontendStateComponent大厅流程FControlFlow/LobbyBackground)、IndicatorSystem(头顶指示器3D→2D投影:IndicatorDescriptor+LyraIndicatorManagerComponent+SActorCanvas+Slate)、PerformanceStats(FPS/内存)、Subsystem(LyraUIManagerSubsystem+LyraUIMessaging模态弹窗)、Weapons(准星Reticle+命中标记HitMarker,S前缀=Slate底层)。命名规律：U=控件/Subsystem/Component/Screen，S=Slate原生，I=接口。
