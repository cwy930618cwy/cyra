# UE5.6 引擎全景地图

> 目标：一眼看懂 UE5 引擎的完整结构，知道每个文件夹是干嘛的、该往哪找代码。
> 
> 和 `UE5.6_源码分析` 的区别：那个是"鸟瞰 + 类继承"，这个是"按模块深入，逐个击破"。

---

## 一、引擎根目录

```
C:\Program Files\Epic Games\UE_5.6\
├── Engine/              ← ★ 引擎本体（99% 的代码在这）
├── FeaturePacks/        ← 功能包（可选安装的扩展）
├── Samples/             ← 示例项目（学习用）
├── Templates/           ← 项目模板（新建项目时的起点）
└── ToolComplete.txt     ← 安装完成的标记文件
```

---

## 二、Engine 目录（核心）

```
Engine/
├── Binaries/            ← 编译产物（.dll / .exe），你不需要看
├── Build/               ← 构建脚本（.bat / .sh），打包时用
├── Config/              ← 引擎默认配置（.ini），了解即可
├── Content/             ← 引擎内置资源（默认材质、音效、蓝图模板）
├── Documentation/       ← 离线文档（.udn = Unreal Document Network）
├── Extras/              ← 附加工具（Python 脚本、性能分析器）
├── Intermediate/        ← 编译中间文件，自动生成，不用管
├── Platforms/           ← 各平台特定代码（Android/iOS/Linux...）
├── Plugins/             ← ★ 插件（GAS、EnhancedInput、MetaHuman...）
├── Programs/            ← 独立程序（UnrealBuildTool、ShaderCompiler...）
├── Shaders/             ← 着色器源码（.usf / .ush），渲染相关
├── Source/              ← ★★★ 所有 C++ 源码（重点中的重点）
└── Saved/               ← 运行时生成的临时文件
```

## 三、Source 目录（源码核心）

```
Engine/Source/
├── Runtime/             ← ★ 运行时（游戏跑起来需要的代码）
├── Editor/              ← 编辑器（只在编辑器里跑的代码）
├── Developer/           ← 开发工具（打包、调试、分析工具）
├── Programs/            ← 独立程序的源码（UBT、UHT 等）
└── ThirdParty/          ← 第三方库（PhysX、FMOD、Vulkan SDK...）
```

### 3.1 Runtime — 运行时模块（最重要）

| 模块 | 作用 | 重要度 |
|------|------|--------|
| **Core** | 引擎基石：容器(TArray/TMap)、字符串(FString/FName)、数学(FVector/FMath)、委托、智能指针、日志、内存分配 | ⭐⭐⭐ |
| **CoreUObject** | UObject 系统：反射、GC、序列化、UClass/UProperty/UFunction | ⭐⭐⭐ |
| **Engine** | 游戏引擎核心：AActor/APawn/ACharacter、UWorld/ULevel、GameMode/GameState/PlayerController、组件系统、碰撞、物理接口 | ⭐⭐⭐ |
| **Renderer** | 渲染管线：延迟渲染、光照、阴影、后处理、Nanite、Lumen | ⭐⭐ |
| **RenderCore** | 渲染核心抽象：RHI 接口、Shader 管理、纹理流送 | ⭐⭐ |
| **RHI** | 渲染硬件接口（D3D12/Vulkan/OpenGL 的抽象层） | ⭐ |
| **Slate** | UI 框架（编辑器界面、UMG 底层） | ⭐⭐ |
| **SlateCore** | Slate 核心（布局、绘制、输入） | ⭐⭐ |
| **UMG** | 蓝图 UI 系统（Widget Blueprint） | ⭐⭐ |
| **AIModule** | AI 系统：行为树、环境查询(EQS)、感知系统 | ⭐⭐ |
| **NavigationSystem** | 导航系统：寻路、NavMesh 生成 | ⭐⭐ |
| **PhysicsCore** | 物理引擎抽象层（Chaos Physics） | ⭐ |
| **AnimationCore** | 动画核心数学 | ⭐ |
| **AnimGraphRuntime** | 动画蓝图运行时 | ⭐⭐ |
| **MovieScene** | Sequencer 时间轴系统 | ⭐ |
| **LevelSequence** | 关卡序列（过场动画） | ⭐ |
| **GameplayTags** | GameplayTag 系统（GAS 依赖） | ⭐⭐ |
| **GameplayTasks** | 异步任务系统（GAS 依赖） | ⭐ |
| **Net** | 网络底层：Socket 抽象、数据包 | ⭐ |
| **Networking** | 网络高层：连接管理、RPC | ⭐⭐ |
| **Json** | JSON 解析 | ⭐ |
| **Launch** | 引擎启动入口（main 函数所在） | ⭐ |
| **MassEntity** | ECS 框架（大规模实体，如千人战场） | ⭐ |
| **Experimental** | 实验性功能（Chaos 物理、GeometryCollection） | ⭐ |

### 3.2 Editor — 编辑器模块

| 模块 | 作用 |
|------|------|
| **UnrealEd** | 编辑器核心（最大最杂，包含各种编辑器基础设施） |
| **BlueprintGraph** | 蓝图图编辑器的节点系统 |
| **Kismet** | 蓝图编译器前端（把蓝图节点转成字节码） |
| **KismetCompiler** | 蓝图编译器后端（生成 C++ 代码或字节码） |
| **Sequencer** | 时间轴编辑器 |
| **Persona** | 动画/骨骼预览编辑器 |
| **MaterialEditor** | 材质编辑器 |
| **ContentBrowser** | 内容浏览器 |
| **LevelEditor** | 关卡编辑器 |
| **SceneOutliner** | 世界大纲（层级面板） |
| **PropertyEditor** | 细节面板（属性编辑） |
| **StaticMeshEditor** | 静态网格编辑器 |
| **SkeletalMeshEditor** | 骨骼网格编辑器 |
| **TextureEditor** | 贴图编辑器 |
| **CurveEditor** | 曲线编辑器 |
| **GraphEditor** | 通用图编辑器框架（蓝图/材质/动画都用它） |
| **DetailCustomizations** | 自定义属性显示（如 FVector 显示为 XYZ 三个输入框） |

### 3.3 Developer — 开发工具

| 模块 | 作用 |
|------|------|
| **AssetTools** | 资产工具（右键菜单、批量操作） |
| **DerivedDataCache** | DDC（着色器/纹理缓存，加速编译） |
| **Localization** | 本地化工具（多语言翻译流程） |
| **TraceAnalysis** | Insights 性能分析数据解读 |

### 3.4 Programs — 独立程序

| 程序 | 作用 |
|------|------|
| **UnrealBuildTool (UBT)** | 编译工具（决定编译哪些文件、链接哪些库） |
| **UnrealHeaderTool (UHT)** | 头文件工具（扫描 UCLASS/UPROPERTY 宏，生成反射代码） |
| **ShaderCompileWorker** | 着色器编译器（后台并行编译 Shader） |
| **CrashReportClient** | 崩溃报告客户端 |

## 四、Plugins 目录（插件生态）

```
Engine/Plugins/
├── Runtime/             ← 运行时插件
│   ├── GameplayAbilities/    ← ★ GAS 技能系统
│   ├── EnhancedInput/        ← ★ 增强输入系统
│   ├── GameFeatures/         ← GameFeature 插件框架
│   ├── CommonUI/             ← 通用 UI 框架
│   ├── ModularGameplay/      ← 模块化游戏框架
│   └── ...
├── Animation/           ← 动画插件（MotionWarping、ControlRig、IKRig）
├── FX/                  ← 特效插件（Niagara）
├── Enterprise/          ← 企业级插件（Datasmith CAD 导入、VariantManager）
├── VirtualProduction/   ← 虚拟制片（LED 墙、摄像机追踪）
├── MetaHuman/           ← MetaHuman 数字人
├── Media/               ← 媒体播放（视频、WebRTC）
├── AI/                  ← AI 插件（ML Deformer、Neural Network Inference）
├── PCG/                 ← 程序化内容生成
├── Compositing/         ← 合成（OpenColorIO、LensDistortion）
└── Experimental/        ← 实验性插件
```

## 五、学习路线建议

### 阶段 1：地基（Core + CoreUObject）
1. **Core** — FString、FName、TArray、TMap、TSharedPtr、FMath、委托
2. **CoreUObject** — UObject、UClass、UProperty、GC、序列化

### 阶段 2：游戏框架（Engine）
3. AActor → APawn → ACharacter 继承链
4. UWorld → ULevel → Actor 生命周期
5. GameMode / GameState / PlayerController / PlayerState
6. UActorComponent / USceneComponent 组件系统

### 阶段 3：关键子系统
7. **GameplayTags** — Tag 系统原理
8. **EnhancedInput** — 输入绑定流程
9. **GAS**（GameplayAbilities 插件）— 五大概念深度整合
10. **Slate/UMG** — UI 系统

### 阶段 4：进阶
11. **Renderer** — 渲染管线概览
12. **Net/Networking** — 网络复制原理
13. **AIModule** — 行为树 + EQS
14. **Sequencer** — 时间轴系统
